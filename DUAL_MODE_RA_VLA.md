# Coding Agent Task: Implementing & Evaluating Dual-Mode Conformal Funnel RA-VLA (CF-VLA) on `Isaac-GR00T-RA-VLA`

## 1. Self-Contained Research Context & Motivation
We are building **Conformal Funnel VLA (CF-VLA)** on top of the **`Isaac-GR00T-RA-VLA`** codebase to solve the long-horizon adaptation bottleneck in In-Context Imitation Learning (ICIL) for Vision-Language-Action (VLA) models.

### 1.1 How Baseline `RA-VLA` Works
`RA-VLA` adapts a flow-matching VLA (`GR00T-N1.5`, with a frozen Eagle-2 VLM backbone $f_\phi$ and a trainable Diffusion Transformer action head $g_\psi$) to unseen tasks at test time without weight updates:
1. **Offline Context Buffer ($\mathcal{B}$):** For an unseen task, $N=3$ expert demonstrations are sliced into segments of length $h=16$ (stride $s=4$). Each segment is cached offline as a key-value pair: retrieval key $\mathbf{z}' = R(\mathbf{V}', L')$ and value $\mathcal{H}' = (\mathbf{H}', \mathbf{s}', \mathbf{A}')$, where $\mathbf{H}' = f_\phi(\mathbf{V}', L')$ are pre-computed VLM tokens, $\mathbf{s}'$ is proprioceptive state, and $\mathbf{A}' \in \mathbb{R}^{h \times D_a}$ is the expert action chunk.
2. **Action-Aware Retrieval & Pairwise Grounding:** During training on 3 `LIBERO` suites, a lightweight retriever $R(\cdot)$ is trained with Dynamic Time Warping (DTW) contrastive loss to retrieve behaviorally aligned segments $\mathcal{H}_{\text{ret}}$ from other demonstrations of the same task. In the action head $g_\psi$, current observation features $\mathbf{H}_t$ are concatenated with retrieved segment features ($\mathbf{H}'_{\text{ret}}$ combined with linearly projected $\mathrm{Lin}_s(\mathbf{s}'_{\text{ret}})$ and $\mathrm{Lin}_a(\mathbf{A}'_{\text{ret}})$) across 8 cross-attention layers.
3. **Informed Flow Initialization & Static Adherence Loss:** Flow-matching denoising ($N_s = 4$ Euler steps, $k \in [0, 1]$) initializes the noisy action chunk at the retrieved action mean $\mathbf{A}_t^{(0)} = \bar{\mathbf{A}}'_{\text{ret}}$ rather than $\mathcal{N}(0, I)$. To force the policy to use the retrieved context, RA-VLA trains $g_\psi$ with a static margin loss:
   $$\mathcal{L}_{\text{overall}} = \mathcal{L}_{\text{rel}} + \lambda \mathcal{L}_{\text{adhere}}, \qquad \mathcal{L}_{\text{adhere}} = \max\big(0, \; m - (\mathcal{L}_{\text{irrel}} - \mathcal{L}_{\text{rel}})\big)$$
   where $\mathcal{L}_{\text{rel}}$ uses DTW-retrieved segments $\mathcal{H}_{\text{ret}}$ and $\mathcal{L}_{\text{irrel}}$ uses randomly sampled segments $\mathcal{H}_{\text{rand}}$.

### 1.2 The Bottleneck of 1-Mode Imitation & Our Dual-Mode Solution
While `RA-VLA` performs well on short-horizon tasks, it achieves only **13.0% success on `LIBERO-Long`**. Because the test buffer $\mathcal{B}$ contains only $N=3$ trajectories, any slight tracking error during an on-policy rollout pushes the robot's current state $o_t = (\mathbf{V}_t, L, \mathbf{s}_t)$ outside the narrow spatial tube covered by $\mathcal{B}$. Once $o_t$ has drifted away from the retrieved state $o'_{t'}$, blindly copying the open-loop expert action $\mathbf{A}'_{t'}$ (or initializing $\mathbf{A}_t^{(0)} = \bar{\mathbf{A}}'_{\text{ret}}$) is ill-posed in control theory and compounds the drift. Similarly, if an off-the-shelf retriever (e.g., SigLIP-2) retrieves a phase-mismatched segment, static adherence forces the robot to copy a wrong action.

**Our Core Idea — Dual-Mode Conformal Funnel Adaptation:**
Instead of treating retrieved segments strictly as actions to copy (1-Mode), we equip the RA-VLA action head $g_\psi$ with **two operational modes** governed by **Relational Context Uncertainty $U_{\text{ctx}}(o_t, \mathcal{H}_{\text{ret}})$** and a conformal trust threshold $\gamma_\alpha$:
- **Mode 1: In-Funnel Action Imitation ($U_{\text{ctx}} \le \gamma_\alpha$):** When the robot is inside the demonstration trust funnel, the retrieved action $\mathbf{A}'_{t'}$ is valid. The model passes $\mathrm{Lin}_a(\mathbf{A}'_{t'})$ into cross-attention and initializes $\mathbf{A}_t^{(0)} = \bar{\mathbf{A}}'_{\text{ret}}$, operating identically to RA-VLA.
- **Mode 2: Out-of-Funnel Goal Pullback ($U_{\text{ctx}} > \gamma_\alpha$):** When the robot drifts outside the funnel, $\mathbf{A}'_{t'}$ is no longer valid to copy, **but the retrieved expert trajectory's future state $(\mathbf{H}'_{t'+\Delta}, \mathbf{s}'_{t'+\Delta})$ remains a valid in-distribution milestone (sub-goal anchor)**. In Mode 2, we mask out the expert action embedding $\mathrm{Lin}_a(\mathbf{A}')$ (replacing it with a learnable token `e_goal_mode`), advance the retrieved segment pointer forward by $+\Delta$ steps along the expert trajectory to provide a forward target state $(\mathbf{H}'_{t'+\Delta}, \mathbf{s}'_{t'+\Delta})$, initialize flow matching from standard Gaussian noise $\mathbf{A}_t^{(0)} \sim \mathcal{N}(0, I)$, and let $g_\psi$ act as a goal-conditioned controller that pulls the robot back inside the trust funnel $\mathcal{T}_\alpha = \{o_t : U_{\text{ctx}} \le \gamma_\alpha\}$. Once $U_{\text{ctx}}$ drops below $\gamma_\alpha$, the policy switches back to Mode 1.

## 2. Codebase Exploration & Architectural Modifications
Please first explore the **`Isaac-GR00T-RA-VLA`** codebase to understand how the training dataset, DTW segment pairing, action head conditioning, flow-matching loss, and rollout evaluation work. Then implement the **Dual-Mode CF-VLA** architecture by modifying four components cleanly:

### 2.1 Dual-Mode Segment Pairing in the Training Pipeline (50% Mode 1 / 50% Mode 2)
We follow the exact Leave-One-Suite-Out setup focused on **`LIBERO-Long`** (train on `LIBERO-Spatial`, `LIBERO-Object`, and `LIBERO-Goal`; evaluate on held-out `LIBERO-Long`). During training of the action head $g_\psi$, split each batch (or sample per instance with probability $0.5$) into two modes:
- **Mode 1 Samples (50% — Action Imitation):**
  Use RA-VLA's standard DTW-aligned segment pairing: for current state $o_t$ in demonstration $i$, retrieve the phase-aligned segment $\mathcal{H}'_{t'} = (\mathbf{H}'_{t'}, \mathbf{s}'_{t'}, \mathbf{A}'_{t'})$ from another demonstration $j \neq i$ of the same task.
- **Mode 2 Samples (50% — Cross-Demo Goal-Anchored Pullback):**
  For current state $o_t$ in demonstration $i$ (optionally adding mild zero-mean Gaussian perturbation $\delta_s$ to the input proprioceptive state $\mathbf{s}_t$ to simulate off-manifold drift), find the DTW-aligned timestep $t'$ in another demonstration $j \neq i$ of the same task, and **shift the target segment index forward along demonstration $j$ by $+\Delta$ steps** (e.g., $\Delta = h = 16$ steps, or $1\text{--}2$ segment strides ahead, clamped to the end of trajectory $j$). Use the state features of this forward milestone $(\mathbf{H}'_{t'+\Delta}, \mathbf{s}'_{t'+\Delta})$ as the context anchor, while supervising the policy to predict demonstration $i$'s ground-truth action chunk $\mathbf{A}_t^{(i)}$.
  *(Rationale: Because object coordinates differ between Demo $i$ and Demo $j$ and action $\mathbf{A}'$ is masked out, the policy cannot memorize absolute demo coordinates; it is forced to infer the object-relative goal state from $(\mathbf{H}'_{t'+\Delta}, \mathbf{s}'_{t'+\Delta})$ and drive the arm toward that milestone in the current scene $\mathbf{V}_t$.)*

### 2.2 Action Embedding Masking (`e_goal_mode`)
In the module where retrieved segment features $(\mathbf{H}', \mathbf{s}', \mathbf{A}')$ are projected and combined for the DiT cross-attention layers:
- Introduce a learnable parameter vector `e_goal_mode` with the same dimension as the encoded expert action $\mathrm{Lin}_a(\mathbf{A}')$ (and optionally a binary mode embedding added to the conditioning tokens).
- For **Mode 1** ($\alpha_t = 1$), pass $\mathrm{Lin}_a(\mathbf{A}')$ as usual.
- For **Mode 2** ($\alpha_t = 0$), replace $\mathrm{Lin}_a(\mathbf{A}')$ with `e_goal_mode` (or interpolate via $\alpha_t \mathrm{Lin}_a(\mathbf{A}') + (1 - \alpha_t)\text{e\_goal\_mode}$), completely hiding the expert action vector so the cross-attention layers attend only to the target milestone state $(\mathbf{H}'_{t'+\Delta}, \mathbf{s}'_{t'+\Delta})$.

### 2.3 Mode-Aware Flow-Matching Noise Initialization ($\mathbf{A}_t^{(0)}$)
In `RA-VLA`, the initial flow state $\mathbf{A}_t^{(0)}$ at $k=0$ is initialized to the empirical mean of the retrieved expert action chunks $\bar{\mathbf{A}}'_{\text{ret}}$.
- In **Mode 1**, keep $\mathbf{A}_t^{(0)} = \bar{\mathbf{A}}'_{\text{ret}}$ (accelerated convergence when inside the funnel).
- In **Mode 2**, initialize $\mathbf{A}_t^{(0)} \sim \mathcal{N}(0, I)$ (standard Gaussian noise, or $\alpha_t \bar{\mathbf{A}}'_{\text{ret}} + \sqrt{1 - \alpha_t^2}\boldsymbol{\epsilon}$ for soft gating). This is essential: if $\mathbf{A}_t^{(0)}$ were still initialized at $\bar{\mathbf{A}}'_{\text{ret}}$ in Mode 2, the 4-step ODE integration would remain biased toward the invalid open-loop action!

### 2.4 Contextual Adherence Loss ($\mathcal{L}_{\text{adhere}}$) Across Both Modes
To ensure the policy does not ignore the forward goal anchor $(\mathbf{H}'_{t'+\Delta}, \mathbf{s}'_{t'+\Delta})$ in Mode 2 due to pre-trained behavioral inertia, apply RA-VLA's margin loss $\mathcal{L}_{\text{adhere}} = \max(0, m - (\mathcal{L}_{\text{irrel}} - \mathcal{L}_{\text{rel}}))$ to **both Mode 1 and Mode 2 samples**:
- For Mode 2 samples, $\mathcal{L}_{\text{rel}}$ is the flow-matching MSE when conditioned on the true forward milestone $(\mathbf{H}'_{t'+\Delta}, \mathbf{s}'_{t'+\Delta}, \text{e\_goal\_mode})$, and $\mathcal{L}_{\text{irrel}}$ is the MSE when conditioned on a randomly sampled segment $(\mathbf{H}'_{\text{rand}}, \mathbf{s}'_{\text{rand}}, \text{e\_goal\_mode})$ with its action also masked. This directly incentivizes the action head to ground its trajectory generation in the milestone state during Mode 2 without requiring any VLM prompt modifications.

## 3. Uncertainty-Gated Two-Mode Inference Pipeline
At test time on held-out **`LIBERO-Long`** tasks ($N=3$ demonstrations per task in buffer $\mathcal{B}$):

1. **Relational Uncertainty $U_{\text{ctx}}(o_t, \mathcal{H}_{\text{ret}})$ & Conformal Threshold $\gamma_\alpha$:**
   - Measure $U_{\text{ctx}}(o_t, \mathcal{H}_{\text{ret}})$ via Velocity-Field Disagreement (VFD) across $M$ ensemble heads / weight-perturbed action heads along the ODE denoising steps:
     $$U_{\text{ctx}}(o_t, \mathcal{H}_{\text{ret}}) \propto \sum_{k} \frac{k}{1 - k} \left\| \mathbf{v}_k^{(1)}(o_t, \mathcal{H}_{\text{ret}}) - \mathbf{v}_k^{(m)}(o_t, \mathcal{H}_{\text{ret}}) \right\|_2^2$$
   - Before online evaluation on each task, compute the **Leave-One-Demo-Out Conformal Threshold $\gamma_\alpha$** ($\alpha \in \{0.05, 0.10\}$, i.e., 95th or 90th percentile) by querying each state in demo $n \in \{1, 2, 3\}$ against the remaining $N-1 = 2$ demos $\mathcal{B} \setminus \{n\}$ inMode 1.

2. **Two-Stage Runtime Execution (Zero Overhead When In-Funnel):**
   At each chunk generation step $t$:
   - Retrieve $\mathcal{H}_{\text{ret}} = (\mathbf{H}'_{t'}, \mathbf{s}'_{t'}, \mathbf{A}'_{t'})$ from $\mathcal{B}$ and run the **Mode 1** forward pass while computing $U_{\text{ctx}}(o_t, \mathcal{H}_{\text{ret}})$.
   - **If $U_{\text{ctx}}(o_t, \mathcal{H}_{\text{ret}}) \le \gamma_\alpha$ (Inside Trust Funnel):** Directly execute the predicted Mode 1 action chunk (zero extra latency!).
   - **If $U_{\text{ctx}}(o_t, \mathcal{H}_{\text{ret}}) > \gamma_\alpha$ (Outside Trust Funnel / Mismatched Context):** Discard the Mode 1 chunk, shift the retrieved segment pointer forward in the same buffer trajectory to $t' + \Delta$ (next milestone segment), replace $\mathrm{Lin}_a(\mathbf{A}')$ with `e_goal_mode`, initialize $\mathbf{A}_t^{(0)} \sim \mathcal{N}(0, I)$, and run the **Mode 2** forward pass of the action head (reusing the already-computed VLM features $\mathbf{H}_t$) to pull the robot back into the funnel.
